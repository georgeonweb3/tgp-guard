Needs a burner key on Ethereum Sepolia testnet in .env (never a real wallet) — full setup in the Reproduce it yourself section below.

The break it caught today

On 11 Nov the third link voter (PREFLIGHT 20260828) silently changed its verdict word from not_listed to Safe. The classifier did not recognise it, so every link check failed closed to HOLD. That is the design working: a silent upstream change surfaced as a HOLD, never as a false ALLOW. The fix (accept Safe / Clean / not_listed as CLEAN) was re-verified live within the hour: 3/3 CLEAN ALLOW on github.com and example.com.

Second opinion on sanctions

Added 11 Nov: Counterproof miner 731002 screens US OFAC + UN + EU + UK lists in a single ask (GET /screen). Its fuzzy matcher can disagree with the exact-name list miners, and the disagreement is recorded, not hidden: "Laden" is BLOCK on OFAC + UN, while Counterproof cleared it (confidence 0.207). A Counterproof-only signal HOLDs for human review and its CLEAR never overrides a list hit.

Live-tested 12 Nov: the Counterproof-only-hit HOLD path now has a real run — "Roman Abramovich" (listed on EU + UK lists only, clear on OFAC + UN) returned HOLD on a Counterproof REVIEW, receipts in evidence/counterproof-hold-2026-11-12.md. Sanctions screening is exact-name only; list coverage differs between miners.

Reproduce it yourself

npm i
echo "EVM_PRIVATE_KEY=0x<burner testnet key>" > .env   # never a real wallet
# Fund the burner on Ethereum Sepolia: a little Sepolia ETH for gas,
# plus test USDC 0xcc194e1a843B658526D0D5C431f670028582Ae17 (open mint).
node --env-file=.env preflight.mjs --asset bitcoin --counterparty "Acme Bakery" --url https://github.com
node --env-file=.env preflight.mjs --counterparty "Laden"          # expect BLOCK
node --env-file=.env guard.mjs bitcoin 50000                        # expect BLOCK (off-market)

Missions

Mission 14 — Web3 Native and DeFi (primary): analysis bought before committing capital, generalised — price, sanctions, link and contract-audit checks before any agent action, one verdict with receipts.

Mission 01 — Exchange: the sanctions screen and multi-source price cross-check are the pre-listing / pre-trade evidence class, returned as one signed-off verdict with a cost line.

Mission 02 — Stablecoin: compliance screening attached to the payment itself as proof — every verdict is backed by per-check Telegraph receipts, and x402 spend is hard-capped per payment ($0.01).

tgp-guard by George Agbe (GitHub georgeonweb3, Discord cryptomillionaire9138, X @georgebuilding2). Testnet only — no production customers yet. Built for Telegraph Hackathon Season II.
Privacy: each check sends only the minimum it needs (a name, a URL, a quote, a contract address) to the miners running that check. No accounts, and run history lives only in the local run log you control.
